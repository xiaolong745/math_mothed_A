# 独立五核全量评估

本批经用户授权，从论文冻结版继续做覆盖验证，不新增算法，也不覆盖原十图成绩。
该批次已结束；本目录保存历史结果与协议。新的批次应在独立工作副本运行。

## 固定协议

- 输入为原始 100 图；每图五核 P1/P2/P3，共 300 格。
- 从 `results/paper_freeze_20260927/snapshot.tar.gz` 解包独立代码。算法、官方 evaluator、配置和输入哈希见 `manifest.json`；原冻结归档校验通过。
- 原 Portfolio、Stage2 和 Pi 参数不变。60 秒是精修预算，不含 Stage1 和 Pi；每次官方调用 300 秒超时，每格进程 900 秒上限。
- 远端 12 个独立进程并发，每个进程地址空间上限 16 GiB；单核官方基线每图计算一次后只读复用。PPU 不参与。
- 每次官方评估成功后立即保存当前最优方案。超时终止所属进程组，保留已验证方案与历史 elite，超时格不冒充搜索完成。
- 预跑按图大小和 DAG 深度选择：小图 019/029/048/070，中图 018/036/043/075，大图 030/041/085/091。先做 36 格，执行门槛通过后自动扩展其余 264 格。
- 扩展门槛检查进程失败及是否获得已验证方案，不依据加速比调参。单格超时记录为覆盖限制，不自动视为资源失败。
- 不对完成或超时格重复采样取最好值。未启用学习代理或驻留宏块。

## 成绩口径

逐格加速比 = 官方单核 Makespan / 最终合法五核 Makespan。每题按图取算术平均，三题等权平均；不使用 OneOp，也不取平均耗时之比。
当前材料没有可核验的额外比赛总分映射，因此报告加速比，不自行换算“官方总分”。

`summary.csv` 始终保留全部 300 行。`group_metrics.csv` 的均值只包括正常完成、有单核分母且最终选择本批官方结果的格子；不完整覆盖时只能称完成子集均值。
历史兜底、部分超时结果和失败均分别标记。官方调用记录中，只有 start 而无结束的调用可能被进程超时中断，汇总已结束调用数时须单列这些未结束尝试。
运行中同步为逐文件快照，文件间可能相差一个刚完成任务；最终静止后同步才是完整一致快照。

## 查看结果

- `report.md`：覆盖进度与分题完成子集加速比。
- `summary.csv`：逐格 Stage1/Stage2/新结果/历史结果、最终选择、耗时与调用统计。
- `best_configs.json`：当前已验证方案与来源。
- `cells/`：进程状态、逐次事件、最佳官方结果及方案。
- `pilot_gate.json`：预跑执行门槛结果（预跑结束后生成）。
- `sync_status.json`：本地最近同步时间。
- `progress_audit.json`：三题共同完成图上的等权均值、缺失单核分母、未结束评估尝试及 Stage1 退化检查。

同步工具已改为显式参数：`python3 -m tools.sync_full5_progress --host user@host --remote-dir /path/to/results --output results/remote_copy`。
增加 `--watch` 持续同步；`--detail` 下载逐格原始记录，默认只同步汇总。
本 Git 发布不包含 `cells/`、进程日志和同步状态等大体积或本机相关文件。
`progress_audit.json` 不在发布文件中：原同步在结束前中断，其旧快照不能代表最终成绩。

冻结十图历史成绩仍为 P1 3.459816×、P2 4.482766×、P3 4.568239×，三题平均 4.170274×；不能视为本批 100 图成绩。
