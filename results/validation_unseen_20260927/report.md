# Untuned Validation

- Selected cases: 8; completed: 4; incomplete/timeout: 4.
- Selection used only graph inventory features: size, compute cycles, DAG depth, level width, and M/V ratio; no validation result was used.
- All completed cases use k=4, the frozen Stage 1/Stage 2/Pi code and the frozen budget parameters.
- Incomplete cases and timeout reasons are retained in `summary.csv`.
- Results are validation evidence for untuned graphs, not a claim about all 100 input cases.
